## Rules (deliverability + CAN-SPAM)

1. Separate sending domain (e.g. getfullshowroom.com) with its own mailbox;
   warm it 2 weeks before real volume; 20–40 sends/day ceiling.
2. Plain text. One link. No attachments, no images, no tracking-pixel-heavy tools.
3. Every email: real physical postal address + working opt-out, honored
   immediately. Truthful subject lines only — the ones above pass because
   they're literally true for the prospect they're sent to.
4. Personalize the first line from the CSV (reviews, rating, competitor) —
   this is what separates you from the spam they get daily.
5. Log every send + reply; suppress opt-outs forever.
6. Direct-mail variant: rack card to shop counters — "Google shows
   {competitor} first. Want to see why? Scan this." QR → pitch page.
